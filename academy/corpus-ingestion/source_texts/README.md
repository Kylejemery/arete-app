# Source Texts

Drop plain .txt files here for ingestion.

Naming convention: Author_Title_BookOrSection.txt
Examples:
  Epictetus_Enchiridion_English.txt
  Epictetus_Enchiridion_Greek.txt
  Marcus_Meditations_Book1_English.txt
  Seneca_Letters_1-29_English.txt

Files in this directory are NOT committed to git (see .gitignore).
Add source_texts/*.txt to .gitignore.
