One-line: a counselor the user can add to their Cabinet — category and level badges, name, one honest line.

```jsx
<CounselorCard name="Seneca" category="stoics" level="firm" selected
  blurb="Rich, compromised, honest about both. Letters to a friend who was trying." />
<CounselorCard name="Musashi" category="warriors" level="direct" locked blurb="No wasted motion." />
```

Blurbs are dry and specific, never promotional. Future Self is `alwaysPresent`.
