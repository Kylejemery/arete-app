One-line: the circular gold well icons sit in throughout the app — menu rows, feature cards, counselor avatars.

```jsx
<IconWell name="book" size={40} tint="soft" />
<IconWell size={48}>M</IconWell>
```

Soft tint (8% fill) is for menu and feature rows; strong (15%) for standalone accents. Pass a single letter as children for a counselor initial.
